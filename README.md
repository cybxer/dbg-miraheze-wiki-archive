# Days Bygone wiki archive

https://cybxer.github.io/dbg-miraheze-wiki-archive/

Static archive reader with 151 pages and 647 images. File descriptions and templates are excluded as standalone pages; template content and images remain in articles. The Original source tab preserves the exported text. Only the specified welcome and contribution prompts are omitted from the reading view.

Open `index.html` locally, or use the published GitHub Pages site. No installation or server is needed.

GitHub Pages publishes `main` from the repository root. To update the site, copy the generated contents of the local `website` folder here and push to `main`. Keep `.nojekyll` in place.

Source: Days Bygone wiki on Miraheze, September 8, 2026 export. The dump declares CC BY-SA 4.0 for text. Image credits and licenses are preserved in the original dump.
